# Security Policy

## Supported versions

Security fixes are applied to the latest published version. The `0.0.x` series is currently supported on a best-effort basis while the package is pre-1.0.

| Version        | Supported   |
| -------------- | ----------- |
| Latest         | Yes         |
| Older releases | Best effort |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use [GitHub's private vulnerability reporting](https://github.com/oglofus/drizzle-events/security/advisories/new) to report a vulnerability privately. Include:

- A clear description of the vulnerability and its impact.
- The affected package version and environment.
- Steps to reproduce or a proof of concept, if available.
- Any suggested mitigation or fix.

The maintainers will acknowledge reports as soon as practical, investigate the issue, and coordinate disclosure and a fix with the reporter. Please allow time for a fix to be prepared before publicly disclosing the issue.
